# CYBERNEXUS — Cyborg Landing Page

A responsive cybernetic landing page built for a campus design/development challenge. The concept explores **human × machine convergence** through a HUD-inspired visual language, metallic cyborg illustration, responsive components and lightweight interactions.

## Highlights

- Fully responsive desktop, tablet and mobile layout
- Original inline SVG cyborg artwork — no stock image dependency
- Futuristic HUD / scanning / neural-interface visual language
- Animated hero, system ticker, counters and protocol interface
- Pointer glow and subtle 3D card tilt on desktop
- Accessible semantic structure and reduced-motion support
- Zero framework or build-step dependency

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Inline SVG

## Run locally

### Option 1 — open directly
Open `index.html` in any modern browser.

### Option 2 — local server
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

## Suggested demo flow (35–45 sec)

1. Start on the hero section and briefly show the cyborg visual.
2. Scroll through **Origin** and the animated metrics.
3. Show the **Systems** cards and hover interaction.
4. Scroll to **Protocol** and show the HUD synchronization UI.
5. End on **Initialize connection** and click it to show the terminal sequence.
6. Resize or briefly switch to mobile width to demonstrate responsiveness.
